# Contributing

Useful contributions include a confusing sentence, a translation correction, a
case with more than one defensible answer, or a newly authored scenario.

For a review, name the case ID and language, explain the ambiguity and propose
clearer wording. Use fictional data only. Do not upload employer documents,
customer records, credentials or private screenshots.

For a new case, supply the task, recipient, draft, source documents, expected
flags, decisive evidence and next action. Include both risky and already-supported
output across a case pack. Keep all claims inside the evidence and distinguish a
message approval from permission to execute a transaction or release a system.

Keep sentence and source IDs aligned in EN, FR and DE. German uses Swiss standard
spelling. Add bounded rewrite checks and authored examples without implying they
validate meaning. Run `npm test` and verify the UI in all three languages.

State whether you independently authored or reviewed the content, and disclose
machine assistance. Maintainers should record the review and remaining disputes;
passing tests alone does not make a case independently validated.
